# my-first-mcp

## What it does

my-first-mcp is a TypeScript Model Context Protocol (MCP) server.

It provides tools for managing local tasks, reading local expense data, and fetching posts from an allowed external API.

## Requirements

- Node.js 22 or newer
- npm
- MCP Inspector

## Install

Clone the repository and install the dependencies:

```bash
git clone https://github.com/Entesar-Qandil/my-first-mcp.git
cd my-first-mcp
npm install

## MCP Inspector

To test the server with MCP Inspector, run:

```bash
npx @modelcontextprotocol/inspector npx tsx src/index.ts
